# 任务目标

为「目标程序」实现纯 Lean 4 替代程序。填写输入域、输出、错误、可见副作用及必须覆盖的边界情形。以 reference.sexp 指定的参考程序为观察对象，交付经内核验证的静态 bin/candidate。

SESSION_ROOT 先用 SessionEnv 记录最小可复现观察，再按需要组合终端、文件系统、网络、Git 与 Web 工具。记录夹具、输入、超时、输出字节、错误流与退出状态。用确定性种子复现并缩小分歧。

从可判定的 T0 开始建立精化塔。为每一层写出对象边界、端口投影与可检验的行为定律；在纵向提升与横向重构中分别证明交换方块。把最终观察量写入 CliApp 或 ReactiveApp 的模拟世界契约。将算法设计留给拥有该模块的封闭节点。

列明最终入口与回放用例。用 build-exe 从封存树生成候选程序，在相同初始条件下对称运行 ref 和 cand。finish 的验收条件包括整树重审和与本次构建相符的回放收据。
