从基本类型 A、B 出发，用类型构造子 ⊗ 形成 A⊗A、A⊗B、A⊗A⊗A 等复合类型。每个类型 S 都标记拼接范畴 𝒞 中的一个块，块中的对象叫作该类型的点。A⊗B 自己就是一个块，同时保留 A、B 两个分量的位置，供接线时选取。

# 颜色怎样翻译

设 F∶𝒞 → 𝒟 是源、靶拼接范畴之间的普通函子。称它保类型，是指有一个类型翻译 ρ，使 F 把整个 S 块送入 𝒟 中的 ρS 块，并且按下式翻译复合类型

```math
\rho(S\otimes T)=\rho(S)\otimes\rho(T).
```

例如 ρ(A) = X、ρ(B) = Y 时，A⊗B 块中的点被送到 X⊗Y 块。若 b、b′ 都在 B 块，块内箭头的翻译就有确定的类型

```math
f\in\operatorname{Hom}_{B}(b,b')
\quad\Longrightarrow\quad
F(f)\in\operatorname{Hom}_{Y}(Fb,Fb').
```

这说明了为什么 Hom(B,B) 中的箭头不会被送到两个不同块之间的 Het(X,Y)。即使 b 与 b′ 是不同的点，Fb 和 Fb′ 也同属 Y 块。

# 多箭头沿一个分量复合

设 f∶A⊗A → B⊗C，g∶B → D⊗D。选中 f 的 B 输出和 g 的 B 输入，把这两个端口接成一根内部线。约定将 g 的输出放回原来 B 的位置，所得箭头为

```math
g\circ_B f:A\otimes A\longrightarrow D\otimes D\otimes C.
```

C 从 f 直接通到外面。若同一类型出现两次，还要指定接哪一次。这个操作叫沿一个端口的部分复合（cut）。模型须给出这种接法。若 ⊗ 也能把箭头并排，本例可写成 (g ⊗ id_C) ∘ f。部分复合有单位律和结合律，同一接线图上彼此独立的 cut 可以交换次序。[Johnson 与 Yau，§2.5](https://www.sas.rochester.edu/mth/sites/doug-ravenel/otherpapers/johnson-yau20.pdf#page=70)

# 用靶的箭头族拼出源操作的译文

把上例放在靶中。让 f 取遍靶箭头族 R，让 g 取遍靶箭头族 S。这里的 poly-profunctor 就是按各输入、输出对象给出箭头集合的函子，输入反变、输出协变。沿 B 接线得到整族 W。设 B 是小范畴，固定外部对象时，这个集合由余端给出

```math
W(a_1,a_2;d_1,d_2,c)
=\int^{b\in B} R(a_1,a_2;b,c)\times S(b;d_1,d_2).
```

W 的一个元素由内部对象 b 和在 b 上接得起来的一对箭头表示。沿内部线的一个态射可以接到 R 的输出端，也可以接到 S 的输入端，两种表示给出同一元素。c 始终是外部参数，所以不参与这个余端。[Koudenburg，例 1.3 的余端复合](https://arxiv.org/pdf/1402.0250#page=5)

现在设源签名有一个基本操作 H，其边界经 ρ 翻译后为 A⊗A → D⊗D⊗C。**直接指定 H 的译文为靶表达式“R 的 B 输出接到 S 的 B 输入”**，记作 F(H) = S ∘\_B R = W。若 H 已有集合值语义，则还须说明每个源元素如何译入 W，即在翻译后的边界上给出自然映射 H(𝐱;𝐲) → W(F𝐱;F𝐲)，其中 F 逐分量作用。若要求靶表达式精确表示 H 的已有语义，这个比较应当是自然同构。

# 翻译必须保持部分复合

对任意可沿源类型 U 接线的多箭头 p、q，要求

```math
F(q\circ_U p)=F(q)\circ_{\rho U}F(p).
```

这就是从单子态射借来的代入原则。先给每个源基本操作选择一个由靶操作拼成的表达式，然后把源复合式中的每个操作换成它的译文，沿原来选定的端口接回去。若源有定义等式，两边的译文须在靶中相等。保类型的普通函子还须与这套部分复合相容，才能翻译整张接线图。

# El 把底层的值和多箭头提升到上层

给每个底层值（对象）a 指定一个范畴 El(a)，作为 a 的上层类型。El(a) 中的对象是位于 a 上方的点，它的态射位于底层恒等箭头上方。对一支底层多箭头 f，也指定一个上层箭头族 El(f)。选定各端口上的上层对象后，这个族的值就是**具有这些端点、且投影为 f 的所有多箭头**。displayed category 用底点索引对象、用底箭头索引箭头，这里沿用这一思路处理多个端口。[Ahrens 与 Lumsdaine，定义 3.1 和 3.8](https://lmcs.episciences.org/5252/pdf#page=5)

**部分提升。** 给定 f∶a₁⊗a₂ → a₃，保留 a₁ 作为底层参数，只提升 a₂ 和 a₃。把所得族记作 H，其混合类型和集合值写法分别是

```math
H:\ a_1\otimes\mathrm{El}(a_2)\nrightarrow\mathrm{El}(a_3),
\qquad
H(a_1;-,-):\mathrm{El}(a_2)^{\mathrm{op}}\times\mathrm{El}(a_3)\longrightarrow\mathbf{Set}.
```

这里的带斜线箭头表示 profunctor。给定 x₂ ∈ El(a₂)、x₃ ∈ El(a₃)，H(a₁;x₂,x₃) 收集第一输入仍为底值 a₁、其余端点为 x₂ 和 x₃ 的 f 上方的箭头。若连第一端口也提升，它才多出一个可变的上层输入 x₁ ∈ El(a₁)。

**单点上的 endo-poly-profunctor。** 固定一个底点 ⋆，令 E = El(⋆)。对于底层每支 u∶⋆⊗⋯⊗⋆ → ⋆⊗⋯⊗⋆，设它有 m 个输入、n 个输出。全部端口提升后得到

```math
\mathrm{El}(u):(E^{\mathrm{op}})^m\times E^n\longrightarrow\mathbf{Set}.
```

“endo”指每个输入、输出都在同一个范畴 E 中，各端口仍可选不同的对象。**这个底点上全部的上层多箭头类型都在这里。** 选 m、n 和底操作 u，再选 E 中的输入、输出对象，就得到相应的箭头集合。同一端口数下的不同底操作仍分别索引自己的箭头族。

提升也与前文的拼接相连。若上层箭头分别位于 f、g 上方，并且待接端口选中了同一个纤维对象，它们沿该端口的复合便位于底层复合 g ∘\_B f 上方，其中 B 是两个底端口共有的类型。
